# FOOLISH ARC — 90-Day SEO Growth Plan
**Date:** 2026-11-17  
**Site:** https://www.foolisharc.com/  
**Disclaimer:** This plan outlines tasks and targets; it does not promise rankings or guaranteed traffic. Execution depends on owner approvals and external account access.

---

## Month 1 — Foundation & Technical Cleanup

**Goal:** Make the site technically sound, crawlable, and indexable.

**Week 1:**
- [ ] Deploy code + `vercel.json` 301 redirects to production (owner approval)
- [ ] Confirm all 4 domain variants resolve to `https://www.foolisharc.com/`
- [ ] Publish owner-approved policy page content (replace `[OWNER APPROVAL REQUIRED]` placeholders)
- [ ] Add policy links to footer (done in code; content needs approval)

**Week 2:**
- [ ] Verify GSC property (www domain); submit `https://www.foolisharc.com/sitemap.xml`
- [ ] Install/verify GA4; configure ecommerce events (product view, add to cart, checkout, purchase)
- [ ] Run PageSpeed Insights + Lighthouse; document baseline Core Web Vitals

**Week 3:**
- [ ] Run Rich Results Test + Schema.org Validator on homepage and representative products
- [ ] Fix any structured data errors
- [ ] Add owner-approved contact details to Organization schema (address, phone, email)

**Week 4:**
- [ ] Confirm policy pages indexed; confirm /track remains noindex
- [ ] Review GSC Crawl Stats and Page Indexing; resolve coverage issues
- [ ] Month 1 report: technical health, indexed page count, baseline metrics

**Exit criteria:** No critical technical errors; www canonical live; sitemap submitted; policy pages published.

---

## Month 2 — On-Page & Content

**Goal:** Unique, search-intent-aligned content across all indexable pages.

**Week 5:**
- [ ] Complete Semrush Keyword Magic research (paid access required)
- [ ] Finalize keyword-to-page mapping (KEYWORD_MAPPING.csv)
- [ ] Optimize homepage + category metadata (done; review performance)

**Week 6:**
- [ ] Publish 2–3 original blog articles from the planned list (e.g. "How to Choose the Right Fit for Barrel Jeans", "How to Style an Oversized Cotton Shirt")
- [ ] Each article: unique metadata, original imagery where available, natural internal links to relevant products
- [ ] No thin or AI-filler articles

**Week 7:**
- [ ] Run Semrush Site Audit; fix errors and critical warnings
- [ ] Run On Page SEO Checker on priority pages; apply relevant recommendations
- [ ] Add descriptive alt text + dimensions to remaining images (done for key images)

**Week 8:**
- [ ] Set up Semrush Position Tracking (Pakistan, commercial keywords, weekly)
- [ ] Review product schema; add AggregateRating ONLY if genuine review data exists
- [ ] Month 2 report: keyword rankings baseline, indexed blog posts, crawl health

**Exit criteria:** All pages have unique metadata; 3+ original articles published; no critical Site Audit errors.

---

## Month 3 — Authority & Expansion

**Goal:** Build visibility, begin backlink acquisition, scale content.

**Week 9:**
- [ ] Run Semrush Backlink Analytics; identify quality referring domains & outreach targets
- [ ] Do NOT disavow automatically on toxicity scores; investigate toxic-looking links manually
- [ ] Identify competitor backlink gaps

**Week 10:**
- [ ] Publish 2–3 more blog articles (e.g. "Men's Denim Fits Explained", "Build a Minimalist Wardrobe")
- [ ] Internal linking audit: ensure every important page reachable via navigation or internal links
- [ ] Add ShippingDetails + MerchantReturnPolicy schema (once terms approved)

**Week 11:**
- [ ] Assess Google Merchant Center eligibility; prepare accurate product feed (URLs, prices, availability, images must match live store)
- [ ] Review GSC structured data enhancements; expand rich results where eligible
- [ ] Mobile usability check; fix any CLS/INP issues

**Week 12:**
- [ ] Full SEO audit re-run; compare to Month 1 baseline
- [ ] 90-day report: rankings, organic traffic (GA4/GSC), indexed pages, Core Web Vitals
- [ ] Plan next 90 days based on performance data

**Exit criteria:** Measurable improvement in indexed pages and keyword visibility; no technical regressions.

---

## Ongoing (Monthly)

- [ ] Review GSC Coverage, Crawl Stats, structured data enhancements
- [ ] Monitor Position Tracking weekly; adjust keyword targeting
- [ ] Publish 1–2 original content pieces per month (quality over quantity)
- [ ] Monitor product catalogue changes; ensure sitemap auto-updates (it does via build)
- [ ] Re-verify redirects and canonicals after any theme/deploy changes

---

## Owner-Approval Dependencies (block Month 1–3 if unresolved)

1. Shipping / Returns / Privacy / Terms / Size Guide content
2. Business contact details (address, phone, email)
3. Confirmation of delivery/return/exchange claims ("2–3 days", "14-day", "complimentary resizing")
4. Sustainability/fibre claim substantiation
5. Production deployment authorization
6. GSC / GA4 / Merchant Center / Semrush account access
